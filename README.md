# Gestor Académico

Aplicación web para la gestión de prácticas profesionales y cursos de formación.

## Configuración local

Para trabajar en local deben realizarse los siguientes pasos:

1. Copiar el archivo `.env.example` a `.env` y configurar las variables de entorno necesarias.
2. Crear un entorno virtual y activar el entorno virtual.
3. Instalar las dependencias del proyecto con `pip install -r requirements.txt`.
